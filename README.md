# 🧹 CleanSweep

**Утилита очистки диска для Windows с премиум-интерфейсом.** Удаляет временные файлы, кэш, историю браузеров, корзину, DNS-кэш и буфер обмена — прозрачно, безопасно, в один клик.

## ✨ Возможности

- 🗑️ **Временные файлы** — `%TEMP%`, `%LOCALAPPDATA%\Temp`, системный `Temp`
- 🧊 **Кэш эскизов** — thumbnails и iconcache
- 🌐 **Браузеры** — кэш, история, cookies (Chrome, Edge, Brave, Opera, Firefox)
- ♻️ **Корзина** — очистка для всех дисков
- 🌍 **DNS-кэш** — `ipconfig /flushdns`
- 📋 **Буфер обмена** — очистка содержимого
- 📊 **Отчёт** — сколько объектов удалено и сколько места освобождено

## 🎨 Интерфейс

- Тёмная и светлая темы по системной (дизайн по Apple HIG)
- Сайдбар-навигация, прогресс-кольцо «Уровень чистоты», живой журнал
- Плавные анимации, стеклянные панели, аккуратные акценты

## 🛡️ Безопасность

- Перед удалением — подтверждение
- Занятые файлы пропускаются, а не ломаются
- Журнал ведётся только в памяти, на диск не пишется
- Опциональная точка восстановления перед очисткой
- Удаляется ровно то, что отмечено в чек-листе — без скрытых действий

## 📖 Как пользоваться

1. Запусти `CleanSweep.exe`
2. Отметь галочками, что чистить (всё включено по умолчанию)
3. Нажми **Очистить** и подтверди
4. Смотри отчёт: объекты и освобождённое место
